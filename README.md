# AI-Powered Assistive Ecosystem for Visually Impaired

## 📌 Project Overview
A multi-modal assistive web application designed to empower individuals with partial vision impairment. This platform integrates Computer Vision, NLP, and Voice AI to assist with daily tasks, banking, and environmental awareness.

## 🚀 Key Features
* **Voice-Interactive ATM:** Secure financial transactions using speech commands and spoken feedback.
* **Environmental Awareness:** Real-time object detection and face recognition for personalized interaction and safety.
* **OCR Text Extraction:** Converting printed and handwritten text into digital speech using Optical Character Recognition.
* **AI Chatbot:** A virtual assistant for real-time guidance and conversational support.

## 🛠️ Technical Stack
* **Language:** Python
* **Vision:** OpenCV, TensorFlow, Pytesseract (OCR)
* **Voice:** Speech-to-Text (STT) & Text-to-Speech (TTS)
* **Web:** Flask / Django

## 💡 Motivation
This project aims to bridge the accessibility gap in digital services, providing autonomy and dignity to visually impaired users through socially responsible AI technology.
